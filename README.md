# Rakibul Islam, portfolio

Plain HTML, CSS and a little JavaScript. No build step, no dependencies.

- Live: https://just-bul.github.io/PORTFOLIO-RAKIBUL/
- Run locally: `python -m http.server 5179`, then open http://127.0.0.1:5179

## Security

- Strict Content-Security-Policy (same-origin only, no inline scripts or styles).
- `rel="noopener noreferrer"` on every external link.
- No third-party scripts, fonts, trackers or forms. The font is self-hosted.
